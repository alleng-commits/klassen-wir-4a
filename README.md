# Aus vielen Ichs wird ein WIR – Klasse 4a

Digitale fächerübergreifende Unterrichtsreihe als **120-minütiger Projekttag** mit Deutsch, Mathematik, Sachunterricht, kooperativem Brückenbau und Reflexion.

- [Digitale Unterrichtsreihe](index.html) – Lehrerbereich, Schüleraufgaben, Unterrichtsphasen und Nachhaltigkeit
- [Druckbare Arbeitsblätter](arbeitsblaetter.html) – vier Arbeitsblätter mit Gruppenkarten

## Website aktivieren
In **Settings → Pages** Source **Deploy from a branch**, Branch **main**, Folder **/(root)** wählen und **Save**. Nach erfolgreicher Veröffentlichung: https://alleng-commits.github.io/klassen-wir-4a/

## Hinweise
Die Reihe ist für 120 Minuten ohne zusätzlich geplante Pause ausgelegt. Keine echten Konfliktfälle mit namentlicher Zuordnung in der Gruppe diskutieren, und individuelle Reflexion nicht verpflichtend vorlesen lassen. Digitale Antworten werden nicht an einen Server gesendet. Bilder sind derzeit einfache Symbole; ergänzende Illustrationen können später ergänzt werden.
